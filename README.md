## What gets built

`argus` + KeeperHub as the execution layer. Argus detects DeFi anomalies
deterministically. KeeperHub executes the response — compose workflow, dry run,
execute. Nothing re-inferred at execution time. Audit trail on every run.

3. Transaction hash executed through KeeperHub (testnet fine)
